# Задание 1-4

### Текст задачи
выполнить в виде статических методов одного класса
1 В файле найти произведение максимального и минимального элементов.
2 Вычислить количество нечётных элементов
3 Создать новый текстовый файл, каждая строка которого содержит длину строки исходного
файла.
4 Сформировать новый файл на основе исходного по следующему правилу: сначала туда
записывается первый элемент исходного файла, затем — первый и второй, затем — первый,
второй, третий, и т.д., на последнем шаге — все элементы исходного файла.

### Алгоритм решения

1.Был создан статический класс Task5-1 который содержит 2 поля ссылку на директорию файла и длину
2. из основного класса вызываем статический метод для создания файла, в этом методе записываем в поле лен длину строки какую мы хотим создать 
3. создаем файл по указанному пути, запрашиваем рандомное число у метода рандом
4. циклом заполняем файл (также в цикле проверяем как именно необходимо заполнить, зависимость идет от флага если фалаг true то заполняем файл по одному элементу в строке или в противном случаи несколько элементов в строке)
5. После создания файла мы попадаем в метод по сбору информации с файла в зависимости от ключа идет выбор что именно мы хотим посчитать (в зависимости от задания)
